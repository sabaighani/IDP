# Build steps

One note per step of the build. Each step ends with a working repository state, marked with a git tag (`step-00`, `step-01`, ...).

**Each note contains**
- The goal and the visible result of the step
- How the step connects to the previous ones
- The commands to reproduce it
- Common problems and how to fix them

To follow along, check out the tag for the step you want:

```
git checkout step-03
```
